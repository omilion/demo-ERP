# Cobranza

## Qué es
Gestión de las facturas pendientes de cobro a clientes y el seguimiento de los saldos por cobrar.

## Dónde está
Ruta: Menú **Caja → Cobranza** (`/cobranza`).

## Cómo hago lo principal

### Revisar saldos pendientes
1. Entra a **Cobranza**.
2. Filtra por fecha, documento o número interno para ubicar las facturas a gestionar.
3. Revisa el saldo pendiente y registra las gestiones de cobro.

## Preguntas frecuentes
- **¿Cómo se relaciona con las ventas?** La cobranza nace de las ventas/órdenes; el saldo pendiente es lo que el cliente aún no ha pagado.
- **¿Dónde registro un pago recibido?** Los pagos se registran desde Caja; eso actualiza el estado de pago de la venta.
