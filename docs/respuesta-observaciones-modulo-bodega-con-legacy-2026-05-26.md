# Respuesta a observaciones del cliente - Módulo Bodega comparado contra legacy

Fecha de revisión: 26-05-2026

Fuente cliente: `C:\Users\flipe\Downloads\OBSERVACIONES MODULO BODEGA (1).docx`.

Fuente legacy revisada: `C:\Users\flipe\Downloads\sisgestion\sisgestion`.

Este documento conserva el orden y el texto del cliente. La diferencia frente a la versión anterior es que ahora cada punto se cruzó contra el ERP legacy para convertir los pendientes en requerimientos implementables.

## Hallazgos principales del legacy

- Bodega legacy sí tenía tabla compacta con Foto, Código Interno, ID Marco, Código Barra, Mostrar Web, Nombre, Categoría, Subcategoria, Descuento, Precio Costo, Precio Marco, Stock Crítico, Stock, Estado Inventario y Proveedor.
- Bodega legacy sí tenía exportación Excel y botones masivos para Stock, Precios y Web.
- Formulario legacy de producto tenía Mostrar Web, Categoría, Subcategoría, Precio Costo, Precio Convenio Marco Neto, Stock Crítico, Stock, Proveedor, Estado Inventario, Detalle para Web y Detalle para Licitación.
- Facturas de bodega legacy tenía flujo explícito Crear Nueva Boleta o Factura, elegir bodega/documento/proveedor y luego ingresar detalle para sumar stock y modificar costo.
- Despachos y matriz ventas legacy tenían una vista muy compacta con botones de búsqueda por N° interno, ID licitación, OC, ODT, guía, NC, ND, fechas, cliente y tipo de venta.
