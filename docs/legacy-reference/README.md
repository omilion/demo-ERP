# ERP Legacy Plastimar

Carpeta de referencia para documentar visualmente el ERP anterior.

- Codigo fuente extraido: `tmp/legacy_extract/sisgestion`
- Runtime local: `tmp/legacy_runtime`
- URL local esperada: `http://127.0.0.1:8088`
- Capturas: `docs/legacy-reference/screenshots`

Notas operativas:

- El legado es una aplicacion PHP + MariaDB/MySQL.
- El dump contiene usuarios y claves en texto plano. No publicar credenciales en documentacion para cliente.
- Las capturas deben registrar la vista legacy tal como se muestra, idealmente con nombre de modulo, ruta y fecha.
